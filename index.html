useful fact :**“When you see a number like 3.2e+6 in programming or calculators, it’s just a shorthand for really big or small numbers. The e means ‘times 10 to the power of’. So 3.2e+6 literally means 3.2 × 10⁶, which is 3,200,000. If the exponent is negative, like 4e-3, it means 4 × 10⁻³, which is 0.004. It’s a convenient way to write numbers that are too big or too small to display normally. Important: this e is not Euler’s number — it’s just part of scientific notation.”**

For this project, I avoided using rand() because it is not cryptographically secure and produces predictable sequences, which would make passwords easier to guess. Instead, I used a high-entropy random source (crypto.getRandomValues() in JavaScript) to ensure unpredictability. Password strength depends on both length and character variety—using uppercase, lowercase, numbers, and symbols increases the possible combinations and makes passwords much harder to crack. To illustrate this, the project includes a password crack time estimator, showing how high-entropy passwords resist brute-force attacks, combining security with a clear, user-friendly interface.
